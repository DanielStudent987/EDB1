# UFRN - EDB1 - Prof. Eiji Adachi

## Lista de Exercícios: Busca Binária

### Exercícios

1. **Busca Binária Simples** (`buscaBinariaSimples.cpp`)
   - **Descrição:** Implemente uma função que utiliza a busca binária para encontrar a posição de um elemento em um array ordenado de inteiros. A função deve retornar o índice do elemento, ou `-1` se o elemento não estiver presente no array.

2. **Encontrar o Primeiro Índice de um Elemento** (`encontrarPrimeiroIndice.cpp`)
   - **Descrição:** Implemente uma função que usa a busca binária para encontrar o primeiro índice de um elemento em um array ordenado. A função deve retornar o índice da primeira ocorrência do elemento, ou `-1` se o elemento não estiver presente.

3. **Encontrar o Ponto de Pico em Sequência Bitônica** (`encontrarPicoBitonico.cpp`)
   - **Descrição:** Dado um array de inteiros que aumenta e depois diminui, somente aumenta ou somente diminui, implemente uma função que encontra o elemento "pico" (o maior elemento) usando uma versão modificada da busca binária. A função deve retornar o índice desse pico.

4. **Encontrar a Raiz Quadrada Inteira de um Número** (`raizQuadradaInteira.cpp`)
   - **Descrição:** Implemente uma função que encontra a parte inteira da raiz quadrada de um número inteiro não negativo `N` usando busca binária.

5. **Buscar o Elemento Mínimo em um Array Rotacionado** (`buscarMinimoArrayRotacionado.cpp`)
   - **Descrição:** Implemente uma função que encontra o elemento mínimo em um array ordenado que foi rotacionado em uma posição desconhecida. Use busca binária para encontrar o mínimo eficientemente.

6. **Contar Ocorrências de um Elemento em um Array Ordenado** (`contarOcorrencias.cpp`)
   - **Descrição:** Implemente uma função que conta o número de ocorrências de um elemento em um array ordenado de inteiros usando busca binária. Dica: reuse a solução do problema de encontrar o primeiro índice, implemente uma outra versão que encontra o último índice e use essas duas para contar a quantidade de ocorrências.

7. **Encontrar a Posição de Inserção de um Elemento** (`posicaoInsercao.cpp`)
   - **Descrição:** Implemente uma função que, dado um array ordenado de inteiros e um elemento alvo, usa busca binária para encontrar o índice onde o alvo deve ser inserido para manter o array ordenado. Se o alvo já estiver presente, a função deve retornar o índice de sua primeira ocorrência.

8. **Encontrar o Elemento Mais Próximo** (`encontrarElementoProximo.cpp`)
   - **Descrição:** Implemente uma função que, dado um array ordenado de inteiros e um valor alvo, retorna o elemento do array que é o mais próximo do valor alvo usando busca binária.

9. **Buscar o Elemento Majoritário** (`buscarElementoMajoritario.cpp`)
   - **Descrição:** Dado um array ordenado de inteiros, implemente uma função que usa busca binária para determinar se existe um elemento majoritário (um elemento que aparece mais de `n/2` vezes, onde `n` é o tamanho do array).

10. **Encontrar o Valor de um Elemento que Falta em um Array** (`elementoFaltando.cpp`)
   - **Descrição:** Dado um array ordenado de `tamanho` inteiros contendo os valores de `1` a `tamanho + 1`, exceto um deles, implemente uma função que usa busca binária para encontrar o elemento que falta.
